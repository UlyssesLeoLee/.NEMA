# NEMA v1.4 · 日本語クイックガイド

**標準モードは Table です。** ドメインの先頭には実際の Tab を 1 文字置きます（例：`\tT1 1`）。最初の本文行が **バックスラッシュ＋半角スペース（`\ `）** で始まる場合だけ見出しと判断します。それ以外は最初の行がデータで、見出しは `column1`、`column2`、… と自動生成します。

```text
⇥T1 1
\ Agent State Note
Claude Ready CheckSession
   AccessGranted
```

ここで `⇥` は実際の Tab を図示するための記号です。本文の横方向の列は **1 個の半角スペース** で分離します。行頭 N 個の半角スペースは直前の行の X(N−1) 列の続きとなり、3 個なら 3 列目の意味単位を継続します。ファイル末尾は物理的に空行 2 行で終了します。

`\t?T1 1` は What→Why→How→Who→When→Where、`\t>G1 1` は Node–Edge グラフです。`A>X>B` は Edge ID X の A→B、`A<X<B` は B→A を表します。説明文は縦方向へ続けて書けます。末尾の独立した ` .` は、残りの列が明示的に空であることを示します。

冒頭の `\t$N` は不透明な辞書語 N 個の宣言です。`^0` は辞書の 0 番目を参照し、`Validate^0BeforeAccess` の `APIKey` などを一単位として扱います。日本語や中国語は通常そのまま続けて書きます。独立した `.nemat` 伝送形式は無損失の辞書、数字プレフィックス、RLE を利用でき、復号後の `.nema` と完全一致する必要があります。

現行のベンチマークはローカル SentencePiece を使った測定であり、商用モデルの課金 Token 数や学習済みモデルの生成精度を保証しません。
