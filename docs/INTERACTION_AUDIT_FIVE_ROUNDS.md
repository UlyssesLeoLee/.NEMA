# .NEMA 自动旋转与全站交互 · 五轮自审

> 结论：核心状态机、按钮事件与 AST 结构渲染均通过自动化回归。当前执行环境的 Chromium 被管理策略禁止导航，本报告不声称完成真实浏览器 GPU/屏幕截图验证。

## 第 1 轮：3D 运动机制

**根因**：旧版 Three.js 使用 `Math.sin(t) * .06`、离线 WebGL2 使用 `Math.sin(ms*.00015) * .055`，振幅约 ±3°，实际几乎看不出转动。两实现分别维护旋转状态，无法保证按钮一致。

**处理**：增加共享 `sculpture-motion.js`，默认每 24 秒完成一次 360° 自转；帧时间差限幅；离屏停止推进；暂停冻结；用户拖动/切视角后保持 5 秒再续转；复位保持 2.5 秒；系统减少动画时默认静止，可由用户显式恢复。

**验证**：Node 测试覆盖 3 秒约 45°、暂停冻结、恢复推进、手动视角保持、视角恢复、离屏暂停和复位。`test_interaction_contract.mjs` 通过。

## 第 2 轮：Node–Edge 几何与方向

**根因**：旧图布局在 `n=2` 时使用 `(350+200*cos(±π/2),170)`，两个 Node 坐标完全重合，图形不可读。

**处理**：双节点固定水平分离，三节点三角布局，其他多节点椭圆布局；方向、边 ID、自循环、平行边来自实际解析器 AST；箭头始终指向解析结果中 `to` 节点，反向符 `<` 不以字符串字面猜测方向。

**验证**：正向、反向、无向、自循环和平行边五种示例都检查节点/边数量、位置间距、箭头、点击信息。`test_interaction_contract.mjs` 通过。

## 第 3 轮：用户操作与按钮

**处理**：检查移动导航、前/左/右视角、复位、暂停/恢复、PNG 截图；未加载模型时禁止空白截图，提供状态信息。语法清单弹窗支持关闭、Esc 和遮罩；复制使用 Clipboard API，失败可降级为传统复制并显示状态。

**验证**：`test_controls.mjs` 通过模拟 DOM 事件，逐项确认按钮分发及状态变化。浏览器实机点击未验证。

## 第 4 轮：三模式渲染和性能对比

**处理**：首页 Token 结果仍来自原始数据；现在 Table 显示实际 AST 表格，5W1H 显示真实六字段，Node–Edge 显示真实节点/关系图。用户切换 .NEMA / JSON / YAML 时显示同一语义样本对应源码，同时保留结构示意；所有对照数据保留原值，不杜撰新的 Token 结果。

**验证**：`test_semantic_panels.mjs` 检查首页默认 Node–Edge 3 节点 3 边、Table 的真实表格行及 5W1H 六维字段。解释器 Python/JS 的 126 个合法/错误案例和 10 个可逆传输样品由 `tests/test_matrix.py` 验证。

## 第 5 轮：资源一致性、排版及发布完整性

**处理**：顶部开始按钮继续保持不拆字；舞台为单一容器，悬浮控制区独立布局；移动端支持按钮换行、关系图自适应缩放和代码横向滚动；本地服务端口被占用时自动选其他端口。

**验证**：`tests/static_audit.py` 校验 4 个公开页面的全部本地引用、JS 语法、实物 GLB 几何资源及 139 项规则数据；完整 ZIP 交付前做 CRC 检查和 SHA-256 清单。

## 未通过/尚无证据的项目

- Chromium 浏览器在当前环境里对 `http:`, `file:` 与 `data:` 入口均返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此没有可用的真实浏览器截图结果。
- 无真实图形设备/正式 Windows 浏览器的 Three.js WebGL 动画帧率或 360° 模型侧背造型验收。
- 现有模型仍是基于参考图重建的有厚度 3D 浮雕，不是博物馆级 360° 完整圆雕；旋转会暴露背面造型局限。
- 本地 neutral BPE 数字不是商用模型实际 API 计费 Token。
