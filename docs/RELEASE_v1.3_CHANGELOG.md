# .NEMA v1.3 — Release notes

**Scope:** Graph declaration simplification only. Domain headers are unchanged, including `\t>Gauth1 1`. Graph Node and Edge use X0 declarations, X2+ continuations shift left by one ASCII space. Strict relation-operator shape validation prevents malformed Edge downgrade. Existing 5W1H/Table unchanged.

**Delivery:** reference parsers, reversible transport codec, active examples, explicit migration tool, new syntax regression tests, R7 web styling/Three.js retained, three-language Graph guide updated, integration/docs copies, history in archive, file hash manifest.

**Limitations:** existing R7 benchmark/tokenizer data and original R7 training datasets remain historical; post-upgrade model billing savings and real multi-agent/IME integration are not verified by this package.
