# NEMA 品牌与主页交付规范

## 品牌核心

NEMA（阿里阿德涅的线团）：让 Agent 持有可追溯的领域坐标，在复杂的软件协作迷宫中不会迷路。视觉语言为 **深色迷宫 + 金色线团 + 单根连续指引线**。

## Logo 元素

- **外侧三重间断同心圆**：暗示迷宫的岔道、信息拓扑和层级，不使用真实的地图小格，降低小尺寸视觉噪声。
- **中心互相绕合的纱线**：多个 Agent 围绕共享语义结构协作。
- **一根伸向外侧的暖金线**：将可溯源的稳定领域号连接到真实任务。
- 圆形标志不包含人工智能大脑、齿轮、机器人脸等泛化视觉符号。

## 颜色

| 角色 | HEX | 含义 |
|---|---|---|
| 深海底色 | `#0A1525` | 复杂迷宫 / 工程严谨 |
| 线团主色 | `#D9AD69` | 指引 / 信任 / 稳定 |
| 高光 | `#F8DEA2` | 可发现的路径 / 信息 |
| 引导线 | `#F3B56F` | 活跃的协作关系 |
| 正文 | `#F8F5ED` | 清晰、低负荷 |
| 辅助正文 | `#A6AFBA` | 降低非重点视觉权重 |

## 使用规则

- 需要独立标志时用 `assets/nema-logo.svg`（透明底）。
- 需要桌面图标、favicon 或应用时用 `assets/nema-app-icon.svg`（深色圆角底）。
- 单色印刷用 `assets/nema-logo-mono.svg`；应用在深色底。注意该文件中的圆芯目前使用深色留白，仅用于深色画面。
- 为标志保留至少 `0.2 × 图标宽度` 的周围空白。
- 最小推荐像素显示尺寸：原始透明 Logo ≥32px；应用图标 ≥32px。
- 高亮引导线不应当断裂成大量零散装饰点，保持“一根线”的概念。

## 宣传主页

`index.html` 为无构建工具的响应式单页网站，直接打开即能使用。所有资源为相对路径、可脱机访问。它具备：

- 自适应桌面/平板/手机布局；
- `.nema` 文本 / JSON 单域展开 / Schema 切换；
- 多领域选择与 IDE1.0 风格语义解析卡；
- 真实样例、参考规范、验证报告、测试原型 ZIP 下载；
- 浏览器复制按钮与移动导航。

页面里的 `77.8%` 是之前 **1,000 节点本地合成负载的原始字节** 结果，不代表实际 LLM Token 或所有场景的收益。绝不将 NEMA 原型描述为正式生产协议。

## 文件结构

- `index.html`：宣传主页。
- `assets/nema-logo.svg`、`assets/nema-logo-mono.svg`：透明标志。
- `assets/nema-app-icon.svg`：应用图标。
- `assets/*.png`：不同尺寸的像素图。
- `assets/ariadne-maze.webp`：主页神话迷宫插图。
- `assets/social-cover.png`：来自浏览器实际渲染的网页宣传图。
- `training/NEMA_AI_TRAINING.md`：AI 训练 / 提示上下文主文档。
- `training/nema_sft_train.jsonl`、`training/nema_eval.jsonl`：SFT 候选对话样本与测评样本。
- `downloads/`：已验证的原型包及真实 `.nema` 样例。
- `docs/`：NEMA/2 规范、性能与红绿测试报告。
