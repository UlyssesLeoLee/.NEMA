# 旧版 v1.0 → v1.1 迁移设计

**禁止只做 Tab→空格的文本全局替换。** v1.0 默认 5W1H 字段顺序可能是 `Who / What / When / Where / Why / How`，而 v1.1 明确为 `What / Why / How / Who / When / Where`。Graph 与 Table 模式也改变正文列分隔符。需要先按旧版解析出有名字段、节点与边，再生成 v1.1 正文及重新校验。

建议：旧 parser → 旧 AST（领域/字段语义） → v1.1 serializer（列顺序改变） → v1.1 parser → 逐领域语义对比 → hash/版本报告 → 用户确认后写新文件。未实现旧版本 parser 的情况下，迁移器只能**拒绝执行**，不能猜测旧版列的身份。源码文件、Git Diff、JSON 等原生格式永不隐式转换。

若 `.nemat` v1.0 有共享字典，应先用兼容版本的 v1.0 decoder 还原原文，再迁移；切勿把 v1.0 字典索引当作 v1.1 索引复用。历史归档仅供人工审计。**本交付包没有实现 v1.0 → v1.1 自动迁移工具**，不要宣称已完成。
