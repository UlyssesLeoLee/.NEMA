# NEMA v1.1 — 不規則縦方向セマンティック形式（実験仕様）

**正式な詳細仕様は `NEMA_SPEC_v1.1_zh.md` を参照。** v1.1 の横方向（X 軸）は半角スペース `U+0020` 一個で列を区切り、縦方向（Y 軸）は LF で意味単位を追加します。英語は PascalCase を優先し、漢字・日本語の連続文は単語ごとに空白を入れません。必要な場合だけ改行します。

## 三つのモード・What 優先

ドメインの見出しは `TAB + ドメインID + SPACE + 版番号`。先頭に `>` がある場合は Graph。通常のドメインでは最初の本文行が Tab で始まる場合のみ Table、それ以外は 5W1H です。Table の最初の Tab は**モードマーカー**であり、本文の列区切りはスペースです。ドメイン間に空行は不要で、文書末尾の完全な空行二行（末尾 LF 三個）を終端とします。

5W1H の列順は **What → Why → How → Who → When → Where**。What だけで純粋な文章を記述できます。本文の連続するスペースは空列を意味し、勝手に削除してはいけません。セル内の文字どおりのスペースは `\ `、バックスラッシュは `\`、Tab は `\t` と記録します。

英語 `HTTPItIs` は `HTTP it is` と表示できますが、`APIHTTP` のように大文字の略語が連続する場合の境界は自動判別できないため改行してください。正確な大文字小文字を保つ API 名や識別子には `\=APIKey` のリテラル指定を使います。中国語・日本語は単語間の空白を導入せず連続して描画します。

## Graph と伝送

`A>X>B` は A→B、`A<Y<B` は B→A、`A=U=B` は無向関連、`A>P>A` は自己ループです。X0 が Node/Edge、X1 が名称、X2 が説明。縦方向に書き足した説明は同じ Node/Edge に属します。向きはレイアウトから推測せず記号から決定します。

可逆 `.nemat` 伝送は `TAB+$N` の共有辞書、`^N` の完全セル参照、`TAB+数字` の ID プレフィックス、`\^` のリテラルキャレットを使用します。元の `.nema` を**バイト単位**で復元する必要があります。PascalCase を文に戻す表示処理は可逆変換ではありません。詳細は中国語仕様・`NEMA_TRANSPORT_v1.1.md`・`../website/token-benchmark.html` を参照してください。


## Graph 人間向け表示：ホバー説明（R3、構文変更なし）

X0 は ID / 方向、X1 は名前、X2 は任意の説明です。Node / Edge のホバー時に X2 を表示し、Edge には正しい実方向も表示します。縦方向の X2 継続記述は同じ要素に属し、説明の有無でグラフ構造は変化しません。タッチはタップ、キーボードは Tab / Enter / Escape に対応します。これはレンダラーのみの変更で、`.nema` / `.nemat` の構文や Token 計測は変わりません。
