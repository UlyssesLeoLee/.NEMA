# NEMA v1.5 · 发布说明

**破坏性变更：数字领域 ID + 模式专用标记。** 三种领域头改为 `Tab+\1`（默认 Table）、`Tab+?2`（5W1H）、`Tab+>3`（Graph）；revision=1 默认省略，`Tab+\1 2` 表示版本 2。旧的 `T1 1`、`?T2 1`、`>G3 1` 已不合法。

Graph 渲染重新实现：箭头端点锚定目标节点边界，反向 `B<Z<C` 绘制 C→B，多重平行边独立分道，自环有箭头，无向边不画箭头；边可点击并查看说明。

网站中、日、英三语主页和独立 Token 实测页已更新。训练集 300 条、留出评测 80 条及 6 条压缩示范已按数字领域头重建，Python 解析/传输与网页示范使用同源实例。

`.nemat` 保留共享字典、RLE 和无收益回退；旧式字母领域前缀复用暂不生成，`Tab+数字` 保留但本版不接受未经协商的旧选择器。真正 Rust IDE1.0/IME1.0 产品代码仍需另行集成。商业模型真实生成质量与 Token 账单尚未实测。
