# .NEMA v1.5 — Whole-site Art Direction Enhancement

## Purpose
Strengthen readability and editorial image presence while preserving the R7 American-comic, Greek marble, navy-and-gold visual identity. This is a presentation-only release; .nema syntax, parser, training documents, and codec are unchanged.

## Changes
- Increased title / secondary-copy contrast without changing monospace whitespace or parser rules.
- Larger primary Ariadne illustration with less desktop cropping; responsive image bounds.
- Three illustrated editorial pathways linking grammar, graph and documentation.
- Unified picture banners on the syntax inventory and documentation hub.
- Illustrated chapter covers in all HTML documentation pages, with the original Markdown content untouched.
- Improved table, code, dialog and keyboard focus contrast.
- Layered CSS file `website/art-unified-v16.css` last for predictable overrides.
- Reuse of original art assets only; no images containing embedded, potentially inaccurate UI text.

## Checkpoints
- Source order and closing tags validated.
- Local CSS and image paths verified.
- New visual elements are supplementary; interactive grammar modal and interpreter scripts unchanged.
- Manual visual review across actual browsers remains recommended.
