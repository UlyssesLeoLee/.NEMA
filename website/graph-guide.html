.NEMA v1.5 / GRAPH SEMANTICS · HOVER

节点有身份，边有方向，说明是可选内容。

Graph 是 NEMA 三模式之一。X0 定义 Node 或 Edge 身份，X1 是名称，X2 是职责或行为说明。点击展示不需要猜测“Authentication”是什么。

01 / NODE

为什么写 Authentication？

 >G1 1
A LoginAPI Authentication

v1.5 Graph: A LoginAPI Authentication = Node；A>X>B Reads VerifySession = Edge；␠CacheExpired = X2 纵向续写。␠ 仅在讲解中代表真实空格。

Graph 领域头首字符为真实半角 ASCII 空格 U+0020，后紧接 >，无 Tab，也无全角空格。

列原文语义
X0ANode ID，图内引用节点 A
X1LoginAPINode 名称，Graph 的 X1 默认原样保留标识符
X2Authentication可选说明：身份认证。供 AI 理解、搜索和详情展示
X3+…可选扩展属性；不参与箭头语法判断

最短合法 Node

A LoginAPI

不写 X2 也合法。名称已经足够明确时，省略说明更省 Token。

带职责说明的 Node

A LoginAPI Authentication

Authentication 只是说明，不等于 Edge，也不会令系统自动连接某个“认证服务”。

Node 和 Edge 都从 X0 顶格开始；关系符判别 Edge，X1 名称原样保留。一个前导空格用于 X2 纵向续写。Graph X1 的 LoginAPI 已经原样保留，不需要任何特殊前缀。
02 / EDGE

Edge 的 X2 是独立关系的说明

A>X>B Reads VerifySession
 CacheExpiredRetryOnce
列原文语义
X0A>X>BA → B，X 是独立 Edge ID
X1Reads关系名称
X2VerifySession关系说明：校验会话；下一行一个前置空格继续 X2

将鼠标移到节点或连线上即可查看它的 X2 描述；Tab 聚焦也可查看。点击可保持预览，触屏使用点击。

线的方向由 X0 唯一决定；X1、X2 和纵向续写都只是这条 Edge 的内容，不会修改源节点和目标节点。
03 / DIRECTIONS

箭头、平行边、自循环

原文渲染规则
A>X>BA → B正向
A<Y<BB → A反向，不是 A → B
A=U=BA — B无向关联，无箭头
A>P>AA ↻ A自循环
A>X>B + A>Y>BA ⇉ B相同节点之间两条不同 ID 的边
A>X>B + B>Y>AA ⇄ B两个独立 Edge，各自具有内容与身份

正式 Graph 领域头是 >G1 1（ID 加版本）。单独的 >1 是无修订号的无效写法，不符合当前 v1.5 解析器语法。

04 / HOVER · FOCUS · TAP

悬停只读，点击才选中。

Node 与 Edge 的说明都来自 X2。悬停不会添加连线、改变方向、保存文件或请求 AI。

鼠标悬停

移动到节点矩形、关系连线或名称标签，立即显示名称、真实方向与说明；移走后消失。

键盘与辅助功能

Tab 聚焦同样预览；Escape 关闭；Enter / 空格选择，并在常驻字段检查器中显示完整内容。

触屏

首页点击即可选中并查看详情；本说明页轻触固定说明，重复点击关闭，卡片在小屏的图下方展示。

X2 为空时不生成虚构说明；说明只影响可读性，不影响图结构，也不改变 NEMA 的 Token 基准。
