.NEMA v1.5 · 五轮自审报告

日期：2026-11-07。当前版严格以 docs/SPEC_v1.5_zh.md 为准。以下为本交付包内执行的检查范围及结果。旧 v1.2/R7 的历史性能数字未重新标为 v1.5 数字。

第 1 轮：语法一致性与空白字符

通过。 三类领域头 ?ID REV、 ID REV、 >ID REV 均以一个 ASCII U+0020 半角空格开头；原生 .nema 中领域头和显式表头正文均不使用 Tab。隐式 Table 为顶格首条数据、自动 columnN；Graph Node/Edge 顶格，X2/X3 延续。拒绝 U+3000、CRLF、错误文末和非法关系。

第 2 轮：解释器、迁移与可逆传输

通过。 13 项 v1.5 回归用例覆盖原生模式、自动扩列、错误边、版本迁移、Codec 字典无损往返。另校验全部活跃 .nema 示例，以及 60 领域、200 行表格、40 Node/160 Edge 的多领域前缀编解码。修复了 ? 被压缩层错判 Graph 的问题，并使数字领域前缀解压重建出空格领域头。

第 3 轮：网页与交互

通过局部浏览器验证。 语法清单共 21 项，严格三列；点击显示结构化示意，Esc / 点击遮罩 / × 全可关闭。主站第四个示例标签显示自动列名 Table，代码源码从真实半角空格开始。通过 JavaScript 语法检查与局部 DOM 运行测试。

第 4 轮：文档、案例和视觉统一

通过静态一致性检查。 现行规范、AI/IDE/IME 设计、解释器使用、共通字典、迁移、测试与传输案例均提供网页阅读页；历史 v1.2/v1.3 文档保留、分版本标示。美漫原画风及 Three.js 卡通线团未被整体重绘。共通字典 .nemat 样例从真实编解码器生成。

第 5 轮：交付资源、ZIP 与 SHA-256

通过静态链接与 ZIP 完整性检查。 网页本地资源引用全部可解析；完整包及独立解释器包均执行 CRC 检查，MANIFEST_SHA256.txt 列出除自身以外的每个文件。下载页提供独立解释器离线包。

范围限制

  • 浏览器运行验证是在 Chromium 中使用内联页面执行的 DOM 交互，不是全站跨浏览器视觉回归。测试环境限制直接访问 file:// 或本地 HTTP，不能据此宣称完整端到端导航均已实机验证。
  • Three.js 需要 CDN 联网。离线保留原始静态希腊风格画面。
  • 尚未以 GPT/Claude/Gemini 的实际 tokenizer、系统提示词及输出端到端重新测量 v1.5 的 Token 成本。不能承诺必然优于紧凑 YAML。
  • website/syntax.html 的浏览器 JSON 渲染用于展示示意；权威解析与错误校验仍是 Python codec/native.py。
