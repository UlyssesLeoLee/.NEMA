设计要求

Graph Node 和 Edge 从 X0 顶格。点击 Node 显示 ID、X1 名称、X2 描述；点击 Edge 显示方向及关系 ID。X3+ 保持机器标识原样。悬停可显示简要说明，键盘 Enter 激活、Escape 退出。错误方向符号必须以诊断显示，不可创建假节点。
