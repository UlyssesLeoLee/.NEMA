设计要求

IDE 的代码视图必须显示真实半角空格，tab-size:1、letter-spacing:0、word-spacing:0。语法高亮按 ?、 、 > 三种领域头判定；正文 X 坐标从零开始。语义视图允许展开 5W1H、Table 和 Graph；保存回写不得自动增加空格或替换为全角。并发 Agent 使用稳定领域 ID 进行锁定和版本合并。
