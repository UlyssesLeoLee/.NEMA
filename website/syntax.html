写法简明说明具体例子
领域头 / 5W1H
?ID REV		5W1H 领域；首字符恰好一个半角空格，随后 ? 标记模式。 ?Task1 1 BuildLoginFlow PreventLeak VerifyToken Owner Today AuthService
领域头 / Table
ID REV		表格领域；以单个半角空格起始，后面直接接 ID。 Table1 1 Alpha Ready Beta Blocked
领域头 / Graph
>ID REV		图领域；半角空格后紧跟 >，再写领域 ID 和修订号。 >Gauth1 1 A LoginAPI Authentication B TokenStore SessionStorage A>X>B Reads VerifySession
5W1H 六列
What Why How Who When Where		六列固定语义；以一个半角空格横向分隔，多余列报错。 ?Task1 1 BuildLoginFlow PreventLeak VerifyToken Owner Today AuthService
5W1H 纵向续写
X1Text		行首一个半角空格表示续写 X1（Why）。 ?Task1 1 BuildLoginFlow PreventLeak SecondReason
显式表格表头
ColA ColB		Table 领域首条正文使用一个前导半角空格，后接自定义列名。 Table1 1 Agent Status Note Claude Ready CheckComplete
隐式表格 / 自动列
Value1 Value2		Table 首正文直接是数据，自动生成 column1、column2… Tauto1 1 A Ready First B Blocked Second
表格纵向续写
Detail		首列为空续写前一记录；前导两个半角空格定位第三列。 Tauto1 1 A Ready First MoreDetail B Done Last
Node 声明
A Name Description		Graph X0 的节点 ID 顶格；X1 名称、X2 描述。 >Gauth1 1 A LoginAPI Authentication B TokenStore SessionStorage
Edge 正向
A>X>B Label Detail		从 A 指向 B，X 是关系 ID；由 > 识别 Edge。 >Gauth1 1 A LoginAPI B TokenStore A>X>B Reads VerifySession
Edge 反向
A<Y<B Label Detail		从 B 指向 A；Y 是独立 Edge ID。 >Gauth1 1 A LoginAPI B TokenStore A<Y<B Responds SessionReady
Edge 无向
A=U=B Label Detail		A 与 B 的无向关系；U 是独立 Edge ID。 >Gauth1 1 A LoginAPI B TokenStore A=U=B Shares SecurityPolicy
Graph X2 续写
Detail		一个半角空格将描述追加到前一个 Node/Edge 的 X2。 >Gauth1 1 A LoginAPI Authentication MoreDetails
Graph X3+ 扩展
APIKey		前导两个半角空格定位 X3；多一个前导空格定位下一列。 >Gauth1 1 A LoginAPI Authentication APIKey
字面空格转义
\ 		表示单元格内部字面半角空格，不触发分列。 ?Task1 1 Build\ Login\ Flow
字面反斜线
\\		字面反斜线在单元格内双写。 ?Task1 1 C:\\Project
字面 Tab
\t		仅在正文单元格用转义写法，不会作为横向分列符。 ?Task1 1 Hello\tWorld
精确名称标记
\=Name		标识原样保留，避免自动语义拆词。 ?Task1 1 \=HTTP401
共通字典 / 传输
dictionary + .nemat		仅用于可逆传输 Codec；不是 .nema 原生领域语法。原生示例： ?Task1 1 BuildLoginFlow 传输 Codec 见 codec/nemat.py
LF 文末约束
\n\n\n		最后正文行后必须连续三个 LF，不能混用 CRLF。 ?Task1 1 BuildLoginFlow
全角空格禁止
U+3000 ❌		领域头及正文统一禁止全角空格，必须用 ASCII U+0020。正确： ?Task1 1 错误：　?Task1 1

示例内的空格均为半角 U+0020；显式表格表头正文的第一个字符同样为 U+0020。领域头绝不含 Tab 或全角空格。
