02 / HOW IT WORKS
自动选择，不盲目压缩。
SHARED DICTIONARY
共享短语字典
⇥$1
APIKey
⇥?T1 1
Validate^0BeforeAccess
只声明一次可复用原子；^0 在英文中间仍不拆开 APIKey。完整字典声明成本也计入测试。
PREFIX / RLE
数字前缀与字符重复
⇥Task001 1
⇥0
⇥002 1
\16A
传输模式中通过数字选择已发现的领域前缀；\16A 表示 16 个连续 A。只有真实减少 Token 才使用。
SAFE FALLBACK
高熵数据原文回退
⇥T1 1
\ ID Nonce
R001 x3Gm7Qn9
R002 h5Vb1Lc8
随机值没有可复用结构时，词典和压缩头反而更贵；编码器直接返回原始 .nema。
