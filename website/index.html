02 / NODE–EDGE SEMANTICS

  
Node 与 Edge 的每一列代表什么？
Node 行首空格声明节点；Edge 顶格表达方向。Graph X0 负责图的结构，X1 是名称，X2 才是可选说明。说明不会创建额外节点，也不改变箭头方向。
