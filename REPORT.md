# NEMA/2 — Verification & adversarial review (2026-11-06)

## Scope and honesty

**Experimental Python reference prototype**, not a benchmark of true GPT/Claude/Gemini token counts. Network access was unavailable, and the selected model tokenizer was not installed; therefore we measured UTF-8 byte size, gzip-9 byte size, and local CPython parse time. Markdown size is shown for a similarly expressive reference table representation, but unlike JSON/YAML/NEMA it did not undergo machine round-trip decoding.

## Design iteration / three tuning rounds

- R0: domain header once + positional TAB payload + indentation relation slots. No dictionary, no ID shortening.
- R1: optional shared string dictionary; each distinct string gets a reference only when **raw-byte saving is positive**.
- R2: optional group-scoped common ID prefix, with no dictionary.
- R3: use dictionary and ID prefix together (byte-size optimized among the tested combinations for selected workloads).

Runtime `write_auto` chooses the smallest of all four valid combinations against raw UTF-8 bytes, gzip size, or an **injected real model tokenizer**; it refuses to claim token optimization when no such tokenizer exists.

## Red-green tests

- **Red**: 17 tests, one error (`test_patch_update_by_column`) due to mistakenly reading `.fields` instead of the actual `.values` property on patch operations.
- **Fix**: correct domain edit property, enforce full Schema SHA-256 before position-indexed changes, test original input immutability and stale-version rejection.
- **Green final**: **23 / 23 tests pass**, including previous regressions, Unicode, escaped TAB/newline, leading/trailing spaces, wrong indentation, field count, duplicate domain, nonexistent refs, schema order attack, failed-transaction rollback, concurrent domain edits, read/write collision and dependency scheduling.

## Adversarial findings and remaining risk

1. **Positional schema ambiguity**: moving a field silently changes positional meaning. Mitigation: patch includes full SHA-256 schema fingerprint. For snapshot interchange, schema is explicit or provided out-of-band under a versioned manifest.
2. **Whitespaces as syntax**: editors may replace tabs and alter indentation; parser rejects altered or invalid schema and unknown indentation. IDE1.0 must preserve canonical spacing.
3. **Write-set overlap**: independent domain IDs do not guarantee independent **files**. Mitigation: scheduler compares resource `uses`/`touches` and blocks read/write or write/write overlap for shared, identical identifiers. Not sufficient for aliases/symlinks.
4. **Stale revisions**: atomic SQLite CAS permits commits on disjoint domain revisions and rejects conflicts on one revision. A one-domain edit is not a guarantee of file-system atomicity.
5. **Injected commands**: 5-space validation statements are **data**, never executed by the parser. Actual runners must require explicit authorization and sandboxing; untrusted strings must not become privileged instructions.
6. **Lossy compression**: not used; data round trips are exact for supported types. gzip does not determine LLM token count.
